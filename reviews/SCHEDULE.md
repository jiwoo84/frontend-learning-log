# 주제별 복습 일정

날짜는 Asia/Seoul 기준이다. 일정은 복습 요청 시 문제 선정에 사용하며 자동 알림이 아니다.
평가 기준과 계산 방식은 [복습 운영 방식](README.md)을 따른다.

## 확인할 오개념

| 주제 ID | 기존 학습에서 확인한 질문·혼동 | 지연 복습에서 반복된 횟수 | 후속 확인 |
| --- | --- | --- | --- |
| react-state-ref | setter 이후 기존 함수의 state도 바뀐다는 생각, ref 객체와 미리 복사한 값의 차이 | 미평가 | 값의 읽기 시점과 렌더별 참조를 자기 말로 설명하는지 확인 |
| js-event-loop | 비동기 콜백을 단일 큐로 이해, 함수 호출과 콜백 예약 및 Promise 생성 문법 혼동을 설명으로 교정 | 미평가 | 태스크 내부 Promise 예제는 정확히 설명. 지연 인출과 대기 중인 Promise 조건 확인 |

기존 진단 답변을 정식 복습 점수로 소급 집계하지 않았다. 위 주제는 다음 복습 요청 시 기존 학습 범위 안에서 확인할 수 있다. 첫 유효 복습에서 3점이면 3일, 2점이면 1일, 0·1점이면 교정 후 1일을 시작 간격으로 사용한다.

새 주제를 정확히 정리해 학습을 마치면 행을 추가하고 현재 간격 1일, 다음 예정일 학습 다음 날로 등록한다. 정식 복습 전에는 점수와 반복 횟수를 임의로 만들지 않는다.

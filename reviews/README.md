# 복습 기록

사용자가 복습을 요청하면 날짜별 Markdown 파일에 정확히 3문제를 기록한다.

1. 당일 개념 설명
2. 코드 동작 예측 또는 수정
3. 이전 학습 복습 — 이전 학습이 없으면 당일 내용

문제를 낼 때 답은 공개하지 않는다. 답변 후 같은 문서에 실제 답변과 피드백을 추가한다.
미응답, 설명 직후 이해, 독립 정답, 시간 경과 후 재확인을 구분한다.

## 파일 구성

`YYYY-MM-DD.md`에 문제, 실제 답변, 맞은 부분, 수정할 부분, 정확한 설명, 다음 복습 대상을 기록한다.
같은 날짜에 추가 복습을 하면 해당 문서에 회차를 추가한다. 문제에 따라 필요한 코드나 출처를 함께 남긴다.

아직 정식 복습 세트는 없다.

# 복습 기록

사용자가 요청할 때 하루 한 세트, 이미 학습한 내용에서 정확히 3문제를 낸다. 자동 알림은 보내지 않는다.

## 문제 선정

먼저 [주제별 복습 일정](SCHEDULE.md)을 확인한다. 예정일이 지난 주제 중 반복 오개념과 최근 어려움을 우선하고, 나머지는 최근 배운 내용이나 오래 확인하지 않은 내용으로 채운다. 예정일이 아직 안 왔더라도 요청된 세트는 배운 범위에서 구성한다.

가능하면 주제를 섞고 개념 설명, 코드 예측, 수정·적용으로 묻는 방식을 바꾼다. 주제가 하나뿐이면 같은 주제를 서로 다른 각도로 묻는다. 아직 학습하지 않은 내용을 복습 점수에 포함하지 않는다. 기록된 학습 내용 자체가 없다면 임의로 복습 문제를 만들지 말고 학습부터 안내한다.

문제를 낼 때 답은 공개하지 않는다. 답변 후 같은 문서에 실제 답변과 피드백을 추가한다.
학습자의 답변을 요약·익명화했다면 그 사실을 표시한다. 교정한 답변을 최초 답변으로 바꾸어 저장하지 않는다.

## 답변 평가

| 점수 | 기준 | 다음 복습 |
| --- | --- | --- |
| 3 | 힌트 없이 핵심과 이유를 정확하게 설명한다. 적용을 물은 문제라면 그 적용도 정확하다. | 현재 간격에서 한 단계 늘림 |
| 2 | 핵심은 맞지만 일부 누락이나 가벼운 혼동이 있다. 핵심 힌트 없이 스스로 수정할 수 있다. | 현재 간격과 3일 중 짧은 간격 |
| 1 | 핵심 힌트나 설명을 받아야 답을 구성할 수 있다. | 1일 후 |
| 0 | 핵심 원리를 잘못 이해했거나 기억하지 못한다. | 짧게 다시 설명한 뒤 1일 후 |

점수는 운영용 지표이며 전체 역량 등급이 아니다. 답변 길이·말투·결론에 영향 없는 오타는 감점 근거로 삼지 않는다. 결과만 맞고 이유가 잘못됐으면 잘못된 원리를 기준으로 평가한다. 문제가 애매하면 평가에서 제외하고 간격을 바꾸지 않는다. 미응답과 방문하지 않은 날도 오답이 아니다.

힌트 전 최초 답변과 힌트 후 이해를 구분한다. 최초 답변이 0점이었다가 설명 후 이해했다면 최초 점수를 덮어쓰지 않고 교정 여부를 따로 남긴다.

## 간격 조정

- 기본 간격 단계는 **1 → 3 → 7 → 14 → 30일**이다. 검증된 개인 최적값이 아니라 시작을 위한 운영 기준이며 실제 복습 결과에 따라 조정한다.
- 새 주제를 자기 말로 정확히 정리해 학습을 마치면 첫 복습은 다음 날로 잡는다. 당일 학습 중의 답변을 지연 복습 성공으로 집계하지 않는다.
- 예정일 이후의 3점 답변은 한 단계 늘린다. 30일 이후에는 30일 간격을 유지한다. 2점은 `min(현재 간격, 3일)`, 0·1점은 1일로 설정한다.
- 다음 예정일은 실제 복습한 날짜(Asia/Seoul)에 새 간격을 더해 계산한다. 같은 주제를 같은 날 여러 문제로 물으면 가장 낮은 유효 점수로 한 번만 갱신한다. 한 세트에서 여러 번 맞았다고 여러 단계 늘리지 않는다.
- 예정일보다 일찍 낸 보충 문제의 정답은 간격을 늘리지 않는다. 0·1점의 어려움이 드러나면 다음 날로 당긴다. 2점이면 기존 예정일과 복습일+3일 중 빠른 날을 택한다.
- 같은 핵심 오개념이 다른 날짜에 다시 나타나면 반복 횟수를 올리고 다음 출제에서 우선한다. 같은 날 교정 중 반복한 실수는 별도의 지연 복습 실패로 세지 않는다.
- 오류 빈도는 `0·1점이 나온 복습일 수 / 유효하게 평가한 복습일 수`로 기록한다. 점수 2의 가벼운 누락과 핵심 오개념은 별도로 설명한다. 표본이 적으면 비율만으로 결론 내리지 않는다.
- 예정일은 다시 방문했을 때 문제를 고르는 기준이다. 복습을 놓쳤다고 문제 수를 늘리거나 누적 숙제를 요구하지 않는다. 당일 3문제에 포함되지 않은 주제는 다음 세트 후보로 유지한다.

## 파일 구성

- `YYYY-MM-DD.md`: 문제, 주제 ID, 최초 답변, 힌트 사용, 점수와 근거, 오개념, 교정 내용, 변경 전·후 간격과 다음 예정일을 기록한다. 필요한 코드나 출처를 함께 남긴다.
- `SCHEDULE.md`: 주제별 최신 일정과 누적 근거를 유지한다. 날짜별 기록을 근거로 갱신한다.
- 같은 날 이미 출제했으면 미응답 문제를 이어간다. 명시적으로 요청한 추가 세트는 같은 날짜 파일에 회차를 추가한다.

아직 정식 복습 세트는 없다.

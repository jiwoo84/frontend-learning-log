# 프론트엔드 지식창고

대화로 배운 내용을 다시 찾아보고, 코드로 확인하고, 복습하는 개인 학습 기록.
기간을 정하지 않고 하루 한 주제씩 공부한다. 필수 기본기를 고르게 익힌 뒤 심화로 넘어간다.

## 시작하기

- [학습 지도](ROADMAP.md): 필수 영역과 학습 순서
- [진행 기록](PROGRESS.md): 확인한 이해, 남은 질문, 다음 주제
- [State·Ref와 비동기 요청](notes/react/state-ref-and-requests.md): 첫 학습 노트
- [복습 기록](reviews/README.md): 문제와 실제 답변, 피드백
- [복습 일정](reviews/SCHEDULE.md): 주제별 이해 상태와 다음 복습 시점
- [학습 운영 규칙](AGENTS.md): 다음 대화에서도 유지할 방식

이 저장소를 작업 폴더로 연 Codex 세션에서는 `AGENTS.md`의 시작 절차에 따라 최신 학습 기록을 확인하고 이어간다. 학습이 끝나면 기록을 정리하고 커밋·push한다.

새 주제 학습과 그날의 복습은 각각 새 채팅에서 시작하고, 중단한 내용은 기존 채팅에서 이어간다. 주제를 정하면 채팅 제목을 `YYYY-MM-DD | 학습 | 주제` 또는 `YYYY-MM-DD | 복습 | 주제`로 설정한다. 날짜는 시작일의 한국 날짜이며, 여러 복습 주제는 짧게 나열한다.

학습은 한 주제의 질문과 답변으로 시작해 필요한 부분을 깊게 살펴보고, 학습자가 자기 말로 정확히 정리하면 마친다. 복습은 요청한 날 배운 내용에서 3문제를 풀며, 답변의 정확도와 반복되는 오개념에 따라 주제별 간격을 조절한다.

실무 경험을 전제로 기초 원리를 실제 코드와 문제에 연결한다. 답변이 탄탄하면 조건과 제약을 바꿔 난도를 높이고, 이해의 빈틈에는 설명과 실험을 제공한다. 에이전트가 원인·해결책의 보장과 한계·대안의 선택 기준까지 탐구하도록 이끌며, 쉬운 확인 문답만으로 학습을 끝내지 않는다.

마지막 정리는 설명을 보지 않고 짧게 시도한다. 막히면 설명을 듣고 마칠 수 있으며 도움받은 부분을 기록한다. 당일 이해, 자료 없이 설명, 새 조건에 적용, 시간이 지난 뒤 기억을 구분한다. 복습 3문제 중 하나는 조건을 바꾼 적용 문제로 내고, 기억·개념·적용 중 어디서 어려웠는지에 따라 다음 문제를 조절한다.

## 기록 방식

- `notes/`: 주제별 개념, 예제, 실무 연결, 출처. 같은 주제를 다시 배우면 기존 문서를 보완한다.
- `reviews/`: 날짜별 복습 문제, 실제 답변, 피드백. 정답을 보기 전의 생각을 보존한다.
- `PROGRESS.md`: 설명을 들은 것과 혼자 적용한 것을 구분해 기록한다.

보충 설명은 학습자가 이미 익힌 내용과 구분한다. 자료를 읽거나 설명을 들었다는 이유만으로 학습 완료 처리하지 않는다.
